Your files.
A traceable workflow.

Photo Manager Pro keeps an index and operation history alongside your library. Your photographs remain ordinary files.

Import verification

Temporary copies are checked with SHA256 before publication. A local SQLite receipt records the result. Interrupted imports can be retried.

Review and diagnostics

Inspect duplicate candidates side by side, review the cleanup queue and export activity reports. Logs identify errors that need attention.

Optional connections

Receive phone uploads over your local network. Google Drive transfers require the cloud extra and your own OAuth setup; they run only when requested.

Python · Linux & Windows

Python 3.10 or newer. Use a virtual environment. On Windows, replace python3 with py.

python3 -m venv .venv
# Linux:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1
python -m pip install photosync-tool==0.2.1
