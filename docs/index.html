02 / PYTHON · LINUX & WINDOWS

Your terminal. Your setup.

Python 3.10 or newer, in a virtual environment. On Windows, use py instead of python3.

python3 -m venv .venv
# Linux:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1
python -m pip install --upgrade photosync-tool==0.2.1
